3DOD_Snow

이전 상황

이전 미팅에서 눈 환경의 클래스별 포인트 유실률을 분석한 결과, pedestrian은 유실률이 낮고 car/cyclist는 유실률이 높아 해당 클래스 중심의 point cloud augmentation을 진행.

관찰 결과

pedestrian 포인트 유실률: 약 11%

car 포인트 유실률: 약 63%

cyclist 포인트 유실률: 약 36%

수행 실험

KNN, Gaussian jittering 등 interpolation/augmentation 계열 방법 포함 약 10종 내외 실험.

spconv 기반 방법은 노이즈 제거 중심으로 평가.

object-aware 방식은 객체별 특성을 반영해 증강 규칙을 다르게 적용함.

결과 및 해석

일부 설정에서 부분적인 성능 향상은 있었으나, 전체적으로 복원 효과는 제한적임.

특히 car는 포인트가 거의 통째로 사라지는 경우가 있어, 객체를 먼저 인식해야 동작하는 object-aware 방식이 안정적으로 적용되기 어려움.

cyclist는 일부 증강 효과가 시각적으로 확인되었으나, car는 증강이 충분히 이뤄지지 않음.

피드백 및 논의

object-aware 아이디어 자체는 의미 있으나, 현재처럼 LiDAR만 사용해야 하는 조건에서는 객체 종류를 사전에 확정하기 어렵다는 한계가 있음.

모델을 수정하기보다 입력 포인트를 복원/개선하는 방향이 더 적절함.

복원 후 실제 포인트 수가 얼마나 늘어났는지 정량적으로 함께 제시하기를 권장.

후속 조치

point 복원 방향의 기존 방법을 추가 조사.

여러 scene에서 포인트 유실 양상과 복원 가능성 시각화.

증강 전후 포인트 수 변화 및 성능 변화를 함께 보고.

3DOD_Night

이전 상황

기존 baseline(MoME)의 야간 환경 성능 저하 문제를 개선하기 위한 실험을 진행함.

수행 실험

1) 저조도 전처리 모델 3종 적용: 성능 개선 없음.

2) AQR 모듈 파인튜닝: 기존에는 대부분의 쿼리가 LiDAR+Camera 표준 디코더로 라우팅되었으나, 야간 환경에서는 LiDAR 위주로 라우팅하도록 일부 파라미터만 학습함. 그러나 야간 여부를 구분해 학습했다기보다 입력을 맹목적으로 LiDAR 경로로 보내는 경향이 나타나, 유효한 이미지 정보까지 배제되며 성능이 하락한 것으로 보임.

3) Camera neck 파인튜닝: 자원 한계로 neck만 파인튜닝했으며, epoch이 증가할수록 mAP가 하락하여 데이터 부족에 따른 오버피팅 가능성이 제기됨. LLIE와의 조합도 성능 개선으로 이어지지 않음.

선행 연구 조사

LLIE를 활용한 야간 3DOD 연구는 매우 제한적임.

야간 2DOD에서는 LLIE 전처리가 오히려 객체 탐지 성능을 저하시킬 수 있다는 보고도 확인됨.

피드백 및 논의

단순 라우팅 변경만으로는 추가 성능 개선 효과가 크지 않을 것으로 보임.

현재 모델의 99% 수준 fusion 라우팅이 실제 최적값인지도 의문임.

모델 자체가 야간 환경을 대상으로 학습된 구조가 아니므로, 재학습 없이 야간 입력에 강건한 성능을 기대하기는 어려움.

가능하다면 MoME 재학습이 필요하나, 현재 계산 자원이 부족함.

대안으로 다른 멀티모달 baseline(MVMM 등)도 함께 평가하는 방향을 검토함.

LLIE 계열 모델은 평균 성능만 볼 것이 아니라, 실제로 영상 품질이 개선된 케이스와 악화된 케이스를 나누어 성능 차이를 분석하기로 함.

후속 조치

LLIE 결과를 good/bad case로 나누어 분석.

다른 멀티모달 baseline 평가 가능성 검토.

3DGS

이전 상황

지난주 대비 날씨 합성 품질은 개선되었으나, 일부 scene에서는 여전히 뭉개짐이 존재함.

맑은 하늘 장면에 비/눈 효과를 합성하는 설정은 사용 가능하다는 피드백을 받음.

수행 실험

데이터구 구성 방식

원본 데이터를 먼저 3DGS로 reconstruction한 뒤, reconstruction 결과물에 weather effect를 합성하는 방식으로 진행함.

일부 scene은 프레임 수가 최대 800장 수준까지 증가하여, 다른 데이터셋과의 비교 및 시간 문제를 고려해 최대 200프레임으로 샘플링함.

날씨 아티팩트가 없는 시작/끝 구간은 제외함.

실험 진행 현황

이번 주 목표는 최소 2개 scene에 대해 LongSplat과 posed 3DGS 결과를 모두 확보하는 것이었음.

LongSplat(unposed)은 완료되었으나, 기대보다 성능이 낮았고 snow 조건에서 특히 품질 저하가 크게 나타남.

Vanilla 3DGS는 아직 일부 실험이 진행 중임.

원인 가설

posed 3DGS의 SFM 단계에서 사용한 모드 설정 문제 가능성.

데이터셋에 제공된 고품질 camera pose가 의도치 않게 사용되었을 가능성.

따라서 데이터셋을 다시 올려 재실험 중임.

추가 이슈

2D 전처리 모델 실험을 위해서는 weather 합성본과 원본 GT의 pair가 맞아야 하는데, 현재 GT pair 정렬 문제가 있어 해당 작업도 병행 중임.

피드백 및 후속 조치

필요 시 weather 합성 강도를 낮춘 설정도 검토.

unposed 결과가 좋지 않더라도, 원인을 명확히 파악하는 것 자체가 중요한 결과가 될 수 있음.

센터 측에서 가용 서버/장비를 확인해 지원 여부를 검토하기로 함.

다음 주까지 정량 평가 결과를 포함해 다시 보고하기로 함.
