# 2026-05-06 회의록

## 1. 3DOD_NIGHT

### 실험 결과

#### Hard vs Easy 성능 차이
- AP 기준 약 0.5 수준의 성능 차이 발생
- 세 가지 모델 모두 동일한 경향 확인
- 모델 종류와 무관하게 유사한 패턴 관찰

### 결론
- 성능 차이는 모델 구조보다 입력 데이터의 영향이 더 큰 것으로 판단
- 야간 환경으로 인해 데이터 품질이 저하되면서 성능 감소 발생

### 피드백 및 논의

#### 추가 실험 제안: LLIE(Low-Light Image Enhancement)

**실험 구성**
- 원본 야간 데이터
- LLIE 적용 데이터
- Easy / Hard 각각 비교
- Mome 모델 기준 실험 수행

**비교 항목**
- AP 성능 변화
- 밝기 변화

**목적**
- 전처리를 통해 성능이 얼마나 개선되는지 확인

#### 기존 지표 관련 논의

**Noise 관련 지표**
- 패치 기반 표준편차 사용
- 하지만 영상이 어두워질수록 분산이 작아지는 문제 존재
- 따라서 noise estimation 지표로 사용하기에는 한계 존재

**밝기 균일성(Brightness Uniformity)**
- 표준편차 기반으로 측정
- 전체적으로 값이 작게 나타남
- 의미 있는 품질 지표로 보기 어려움

### 향후 계획
- 원본 대비 전처리 결과 비교
- 밝기 변화량 기반 분석 추가

## 2. 3DGS

### 논의 내용

#### 용어 변경 제안
- 기존: **향상률 (Improvement Rate)**
- 변경: **회복률 (Recovery Rate)**

**변경 이유**
- 강설 환경에서 감소한 성능이
- 전처리를 통해 얼마나 회복되었는지 표현하기 위함

### 회복률 계산 방식
- Clean Score
- Snow Score
- De-snow Score

위 세 점수 간 차이를 백분율로 계산하여 표시

### 피드백
- "회복률" 표현 사용 가능
- 다만 PSNR은 일반적으로 퍼센트보다 dB 단위 증가량으로 표현하는 것이 적절
- 여유가 있다면 Figure 크기를 확대하여 가독성 개선
