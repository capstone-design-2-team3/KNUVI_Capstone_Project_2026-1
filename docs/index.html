Adverse-Weather Robust 3D Vision

Abstract

Three case studies for adverse-weather 3D perception and reconstruction.

본 프로젝트는 자율주행 및 야외 3D 비전 시스템이 실제 환경에서 마주치는 야간 저조도와 강설 조건을 중심으로, 3D 객체 탐지와 3D Gaussian Splatting 기반 장면 재구성의 성능 저하 원인을 분석합니다. 단순히 “이미지를 보기 좋게 만드는 것”이 아니라, 전처리 결과가 mAP, AP, PSNR, SSIM, LPIPS, ATE/RTE/RPE와 같은 기계 인지 및 재구성 지표에 실제로 도움이 되는지를 검증합니다.

세부 연구는 ① 야간 환경에서 LiDAR-camera fusion 3D 객체 탐지 모델의 성능 저하 원인 분석, ② 강설 환경에서 LiDAR 포인트 희소화와 포인트 클라우드 복원, ③ 강설 환경에서 2D de-snow 전처리가 posed 3DGS와 unposed LongSplat에 미치는 영향 비교로 구성됩니다.

1. Problems

각 연구는 서로 다른 악천후 실패 요인을 다룹니다.

Night 3DOD

야간에서는 카메라 품질 저하가 LiDAR-camera fusion을 방해합니다.

야간 장면에서는 LiDAR의 객체당 포인트 수는 주간과 유사하게 유지되지만, 카메라 영상의 평균 밝기와 노출 품질이 크게 낮아집니다. 따라서 저조도 영상 개선이 실제 3D 탐지 성능 개선으로 이어지는지 검증해야 합니다.

Snow 3DOD

강설은 LiDAR 포인트를 산란·차단하여 객체 형상을 희소하게 만듭니다.

눈 입자는 LiDAR 신호를 왜곡해 포인트 유실과 허위 포인트를 만들고, 특히 자동차·자전거처럼 형상 정보가 중요한 객체에서 AP 하락을 유발합니다. 실제 강설 데이터 확보가 어렵기 때문에 물리 기반 시뮬레이션 데이터가 필요합니다.

Snow 3DGS

눈 아티팩트와 포즈 추정 불안정성은 3D 장면 재구성을 저하시킵니다.

2D de-snow 전처리는 프레임 단위로 영상을 복원하지만, 잔여 눈 아티팩트가 프레임마다 다르면 multi-view consistency가 깨질 수 있습니다. 이는 COLMAP+3DGS와 LongSplat에서 서로 다른 실패 양상으로 나타납니다.

2. Dataset Construction

각 연구가 어떤 입력 데이터를 사용하거나 구축했는지 정리합니다.

Night 3DOD · nuScenes Night Subset

nuScenes validation set에서 scene description의 night, dark 키워드를 기준으로 야간 장면을 추출하고, 전방 카메라 영상을 확인해 실제 야간 장면만 포함했습니다. 주간 데이터는 해당 키워드가 없는 나머지 장면으로 구성했습니다.

  • Dataset: nuScenes trainval validation set
  • Scene grouping: Hard / Easy by model mAP
  • Quality metrics: brightness, intensity std, under-exposed pixel ratio, LiDAR points/object

3. Method Pipeline

전처리와 3D 모델 평가가 어떻게 연결되는지 연구별로 보여줍니다.

Night 3DOD

야간 데이터 추출·저조도 개선·3D 탐지 평가 파이프라인

raw nuScenes에서 야간 장면을 필터링한 뒤 원본 야간 영상과 CLAHE, EnlightenGAN, ZeroDCE++ 처리 영상을 MoME, BEVFusion, DeepInteraction에 입력하여 저조도 개선이 실제 탐지 성능으로 이어지는지 비교했습니다.

Snow 3DOD

포인트 클라우드 복원 전처리

Snow point clouds를 voxelization 및 feature extraction 후 Sparse U-Net으로 복원하고, HPR filtering과 topology filtering으로 기하학적으로 타당한 completed point clouds를 생성했습니다.

Snow 3DGS

MWFormer 기반 de-snow 후 3D 재구성 비교

Clean, Snow, De-snow 조건을 COLMAP+3DGS와 LongSplat에 입력하여 렌더링 품질과 카메라 포즈 정확도를 비교했습니다.

4. Final Results

각 연구의 목적에 맞춰 최종 결과와 의미를 분리해 정리했습니다.

Night 3DOD

목적: 야간 3D 객체 탐지 성능 저하가 어느 모달리티에서 발생하는지 분석하고, 저조도 개선이 mAP를 회복시키는지 검증

카메라 밝기35.59 → 117.88EnlightenGAN 기준 평균 밝기 증가
BEVFusion mAP0.3546 → 0.3189Zero-DCE++ 적용 시 하락

야간에서는 LiDAR의 객체당 포인트 수가 주간과 유사하게 유지되는 반면, 카메라 평균 밝기와 노출 품질이 크게 저하되었습니다. 그러나 CLAHE, EnlightenGAN, Zero-DCE++는 이미지를 사람 눈에 더 밝고 선명하게 만들었음에도, 세 detector의 mAP를 안정적으로 향상시키지 못했습니다.

Final takeaway: 야간 3DOD의 핵심 문제는 단순한 시각적 밝기 부족만이 아니라, 탐지 모델이 학습한 feature distribution과 맞지 않는 입력 변화입니다. 따라서 인간 시각 중심의 enhancement가 아니라 detection-aware low-light refinement가 필요합니다.

Snow 3DOD

목적: 강설로 인한 LiDAR 포인트 희소화가 3D 객체 탐지 성능을 얼마나 저하시키는지 분석하고, 포인트 복원으로 성능 회복 가능성을 검증

Car points240.46 → 350.39KITTI-Snow → w. Ours
Voxel R-CNN Car AP+1.70Easy 기준 개선

KITTI-Snow에서 자동차 평균 포인트 수는 원본 KITTI 대비 499.93개에서 240.46개로 크게 감소했습니다. 제안한 복원 파이프라인 적용 후 자동차는 350.39개, 보행자는 265.66개, 자전거는 186.22개 수준으로 포인트 수가 증가했습니다.

성능 측면에서는 Voxel R-CNN에서 보행자 Moderate 기준 약 3.74 AP, 자동차 Easy 기준 약 1.70 AP 개선처럼 일부 모델·클래스에서 회복 효과가 확인되었습니다. 다만 자전거처럼 얇고 불연속적인 구조를 가진 클래스는 개선이 제한적이었습니다.

Final takeaway: 강설 3DOD의 주요 원인은 포인트 클라우드 희소화이며, 명시적 포인트 복원은 성능 저하를 완화할 수 있습니다. 그러나 클래스별 구조와 데이터 불균형을 반영한 특화 복원 전략이 추가로 필요합니다.

Snow 3DGS

목적: 강설 환경에서 일반 3DGS와 포즈 추정 3DGS의 강건성을 비교하고, MWFormer de-snow 전처리가 렌더링 품질과 포즈 추정에 미치는 영향을 분석

3DGS PSNR23.845 → 28.493Snow → De-snow, Input GT 기준
LongSplat PSNR21.307 → 23.881Snow → De-snow, Input GT 기준

평균적으로 COLMAP+3DGS는 LongSplat보다 높은 렌더링 품질을 보였고, MWFormer de-snow 전처리는 두 파이프라인 모두에서 PSNR/SSIM/LPIPS를 개선하는 경향을 보였습니다. 특히 3DGS는 Snow PSNR 23.845에서 De-snow 28.493으로 회복되었습니다.

다만 2D 전처리는 프레임 단위 복원이므로 잔여 눈 아티팩트가 프레임마다 다르게 남을 수 있고, 이는 multi-view inconsistency를 유발할 수 있습니다. hydrant처럼 급격한 카메라 회전이 포함된 장면에서는 COLMAP+3DGS와 LongSplat의 실패 양상이 서로 달랐습니다.

Final takeaway: 일반적인 강설 장면에서는 포즈를 선추정하는 COLMAP+3DGS가 전체적으로 안정적이고, MWFormer de-snow는 렌더링 품질 회복에 도움이 됩니다. 그러나 극단적 포즈 조건에서는 unposed 3DGS가 해상도 저하 없이 재구성하는 장점도 관찰되어, 향후에는 전처리와 포즈 추정을 함께 고려하는 통합 접근이 필요합니다.
