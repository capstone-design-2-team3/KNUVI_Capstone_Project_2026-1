Abstract

A unified project page for three papers on adverse-weather degradation in 3D perception and reconstruction.

Modern 3D vision models are typically trained and evaluated in clean daytime environments, but real autonomous-driving and robotic systems must operate under night, snow, rain, and other challenging conditions. This project investigates adverse-weather degradation from two perspectives: 3D object detection, where camera-LiDAR fusion can fail under low light or point-cloud sparsity, and 3D Gaussian Splatting, where weather artifacts and pose-estimation instability can reduce novel-view rendering quality.

The project consists of three case studies: Night 3DOD analyzes why low-light image enhancement does not necessarily improve 3D detection mAP; Snow 3DOD constructs KITTI-Snow and studies LiDAR sparsity recovery through point completion; and Snow 3DGS compares posed 3DGS and unposed LongSplat under snow and MWFormer-based de-snow pre-processing.

1. Problems

Each study starts from a different failure mode: camera exposure degradation, LiDAR point sparsity, and snow-induced reconstruction artifacts.

Night 3DOD

Low-light images disturb camera-LiDAR fusion.

Night scenes show severe camera brightness loss and high under-exposed pixel ratio. Image enhancement improves visual quality, but the enhanced distribution can still be harmful for detection.

Snow 3DOD

Snow makes LiDAR point clouds sparse.

Snow particles cause scattering and occlusion, reducing the object-level point density needed by 3D detectors, especially for cars and cyclists.

Snow 3DGS

2D de-snow may create multi-view inconsistency.

Frame-wise restoration can remove visible snow artifacts, but residual artifacts vary across frames and may interfere with camera pose estimation and 3D reconstruction.

Software Module

The web page also introduces the software-registration scope clearly and separates external MWFormer from the team's wrapper code.

Snow Image Refinement Pipeline for 3DGS Reconstruction receives an aligned snow image folder, runs the external MWFormer restoration model, and exports a de-snow image folder with the same file names and frame count so that LongSplat or COLMAP+3DGS can directly consume the result.

The registration target is not MWFormer itself. The team's software scope is the input validation, execution automation, output collection, LongSplat/3DGS-compatible folder organization, logs, and manifest JSON generation.
