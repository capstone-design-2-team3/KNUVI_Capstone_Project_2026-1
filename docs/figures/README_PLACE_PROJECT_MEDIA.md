# Where to add project photos or videos

This page already includes extracted paper figures from the Snow 3DOD and Snow 3DGS documents.
For stronger visual presentation, you can replace or add media files here.

Recommended file names:

- `night3dod_case.png`: Night 3DOD qualitative result, e.g., original / CLAHE / EnlightenGAN / Zero-DCE++ bounding-box comparison.
- `snow3dod_case.png`: KITTI-Snow point cloud or detection result image.
- `snow3dgs_video.mp4`: Clean / snow / de-snow rendering comparison video.
- `authors/*.jpg`: optional author profile images.

After adding a file, edit `docs/index.html` and change the corresponding `<img src="...">` or `<video src="...">` path.
